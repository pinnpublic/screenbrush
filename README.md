## 사용법

- **필기:** 싸인펜·볼펜·연필과 자유 필기·직선·화살표·사각형·원을 조합합니다.
- **색상:** 단색·사용자 색·순환색을 지원합니다. 도구별 색상은 일반 화면과 화이트보드에서 각각 기억합니다.
- **화이트보드:** 흰색·검정·사용자 색·칠판·노트·도트·사용자 이미지를 배경으로 사용합니다.
- **확대:** `Shift+휠`, 확대 중 **오른쪽 버튼 드래그**로 이동합니다. 최대 배율은 설정에서 600%까지 지정합니다.
- **자동 사라지기:** 완성한 선 전체가 기본 3초 유지 후 1.5초 동안 흐려지며 사라집니다. 기본 꺼짐이며 시간은 설정에서 조절합니다.
- **화면 저장:** 화면과 필기를 PNG로 저장합니다. 저장 위치와 자동 파일명 사용 여부를 설정할 수 있습니다.
- **창 숨기기:** 제목줄 **−**는 트레이로 숨기기, **×**는 앱 종료입니다.

> **Esc**를 누르면 아래 화면을 조작합니다. 기본은 필기·기록 삭제이며, 남기려면 설정에서 **‘Esc 후 필기·기록·확대 유지’**를 켜세요. 앱 종료 전 보관할 필기는 PNG로 저장하세요.

## 주요 단축키

| 기능 | 기본 키 |
| --- | --- |
| 도구 모음 표시 / 숨기기 | Ctrl+Shift+F1 |
| 자유 필기 | Ctrl+Shift+F |
| 실행 취소 / 다시 실행 | Ctrl+Z / Ctrl+Y |
| 모두 지우기 | Ctrl+Shift+Delete |
| 화이트보드 켜기 / 끄기 | Ctrl+Alt+B |
| 자동 사라지기 켜기 / 끄기 | Ctrl+Alt+Shift+A |
| 화면 저장 | Ctrl+Shift+S |
| 원래 배율 | Ctrl+Shift+0 |
| 잠깐 아래 화면 조작 | 왼쪽 Ctrl을 누르는 동안 |
| 앱 종료 | Alt+F4 |

**설정 · 단축키**에서 키를 변경하거나 단축키만 끌 수 있습니다. 버튼은 계속 사용할 수 있으며, 키 변경 즉시 등록 충돌을 알려줍니다. 전체 단축키는 설정창과 버튼 툴팁에서 확인하세요.

## 설정

굵기·불투명도·순환색 속도, 확대 간격, PNG 저장 위치, Windows 자동 실행, 트레이 시작, 마지막 창 위치 기억 등을 조절할 수 있습니다.

다른 PC로 옮길 때는 **배포 폴더 전체**를 복사하세요. 개인 설정은 `%LOCALAPPDATA%\ScreenBrush\settings.json`에 저장됩니다.

## 빌드

.NET 10 SDK가 설치된 Windows에서 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

실행 파일은 `artifacts/ScreenBrush`에 생성됩니다.
