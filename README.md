# ScreenBrush for Windows 사용 매뉴얼

Windows 화면 위에 필기하거나 화이트보드에 글과 도형을 그리는 앱입니다. 싸인펜·볼펜·연필, 도구별 색상 기억, 화면 확대와 이동, 사용자 지정 단축키를 제공합니다.

이 문서는 현재 구현된 기능과 기본값을 기준으로 합니다. 설계와 구현 상태는 [실행계획.md](실행계획.md), 성능 측정과 수정 이력은 [검토 및 수정.md](<검토 및 수정.md>)를 참고하세요.

## 1. 실행과 빠른 시작

### 실행 환경

- Windows 10 2004 이상 또는 Windows 11, x64 환경
- .NET 10 Desktop Runtime 필요
- 소스에서 빌드할 때는 .NET 10 SDK 필요

`ScreenBrush.exe`를 실행합니다. 기본 설정에서는 창을 띄우지 않고 **트레이에서 화면 조작 모드로 시작**합니다.

1. 작업 표시줄 알림 영역에서 ScreenBrush 아이콘을 더블클릭합니다. 아이콘이 보이지 않으면 숨겨진 아이콘 목록을 확인합니다.
2. 도구 모음에서 싸인펜·볼펜·연필 또는 도형을 선택합니다. 도구를 선택하면 그리기가 켜집니다.
3. 원하는 색과 굵기를 정한 뒤 화면에서 왼쪽 버튼을 누르고 드래그합니다.
4. 아래 프로그램을 조작하려면 **Esc**를 누릅니다. 다시 그리려면 원하는 도구 버튼이나 도구 단축키를 선택합니다. 왼쪽 Ctrl을 누른 동안만 일시 조작하는 기능도 유지됩니다.
5. 작업을 마치면 `Alt+F4` 또는 트레이 메뉴의 **종료**를 사용합니다.

**필기 내용은 앱을 종료하면 사라집니다.** 현재 문서 저장·불러오기나 이미지 내보내기 기능은 없습니다. 도구·색상·옵션 등의 설정은 정상 종료 시 보존됩니다.

### 트레이와 창 조작

| 조작 | 결과 |
| --- | --- |
| 트레이 아이콘 더블클릭 / 메뉴의 도구 모음 열기 | 도구 모음 표시 |
| Ctrl+Shift+F1 | 도구 모음 표시 ↔ 트레이로 숨기기 |
| 도구 모음의 − (× 왼쪽) | 창을 트레이로 숨기기 · 그리기 상태 유지 |
| 그리기 중 또는 도구 모음에서 Esc | 화면 조작으로 돌아가기 · 도구 모음 표시 상태 유지 |
| 설정창에서 Esc / 취소 / × | 저장하지 않고 설정창만 닫기 |
| Alt+F4 | 앱 전체 종료. 설정창에서도 전체 종료 |
| 도구 모음의 × / 트레이 메뉴의 종료 | 앱 전체 종료 |
| 도구 모음의 제목 드래그 | 도구 모음 이동 |

화이트보드·확대 창이 표시된 뒤에도 열려 있는 도구 모음은 그 위에 유지됩니다. 사용자가 숨긴 도구 모음을 전환 과정에서 강제로 다시 열지는 않습니다.

도구 모음을 숨겨도 그리기 모드·기존 필기·확대 상태는 유지됩니다. 숨겨 둔 상태에서도 등록된 단축키를 사용할 수 있습니다. 설정창이 열려 있는 동안에는 전역 기능 단축키가 잠시 중지됩니다.

## 2. 필기 도구와 도형

**필기 도구와 그리기 방식은 독립적으로 선택합니다.**

- **필기 도구:** 싸인펜·볼펜·연필 중 하나를 선택합니다.
- **그리기 방식:** 자유 필기·직선·화살표·사각형·원/타원 중 하나를 선택합니다.
- 예: **볼펜 → 사각형**, **연필 → 직선**. 필기 도구를 바꿔도 도형 선택은 유지되고, 도형을 바꿔도 필기 도구는 유지됩니다. 두 선택이 각각 강조 표시됩니다.
- **자유 필기** 버튼 또는 **Ctrl+Shift+F**로 현재 필기 도구의 자유 필기로 돌아옵니다. 이 단축키도 설정에서 변경할 수 있습니다.
- 지우개 사용 후 필기 도구나 그리기 방식을 선택하면 지우개가 해제됩니다. 마지막 필기 도구·그리기 방식은 기억합니다.
- 도형에도 선택한 필기 도구의 표현을 적용합니다. 싸인펜은 일정한 선, 볼펜은 잉크 중심부, 연필은 종이 결의 질감을 사용합니다. 도형의 선 굵기는 지정값을 사용하며 자유 필기처럼 위치별 필압을 기록하지 않습니다.
- 기존 모드별 도구 색상 기억은 유지합니다. 색상은 마지막으로 선택한 필기 도구 또는 도형의 저장값을 불러옵니다. 현재 색상은 팔레트와 색상 이름에서 확인할 수 있습니다.


| 도구 | 특징 / 사용법 |
| --- | --- |
| 싸인펜 | 필압과 이동 속도에 관계없이 지정한 굵기로 그립니다. 곡선 보정을 적용하며 획의 시작과 끝을 가늘게 만들지 않습니다. |
| 볼펜 | 곡선 보정과 필압에 따른 굵기, 자연스러운 획 시작·끝, 얇은 잉크 중심부를 표현합니다. |
| 연필 | 필압과 곡선 보정에 흑연 입자·섬유 질감을 더합니다. 확대하면 질감도 함께 확대됩니다. |
| 직선 | 시작점부터 끝점까지 드래그합니다. Shift를 누르면 방향을 45도 단위로 제한합니다. |
| 화살표 | 시작점부터 화살표 끝까지 드래그합니다. Shift로 방향을 45도 단위로 제한합니다. |
| 사각형 | 대각선 방향으로 드래그합니다. Shift를 누르면 정사각형이 됩니다. |
| 원 / 타원 | 대각선 방향으로 드래그합니다. Shift를 누르면 원이 됩니다. |
| 지우개 | 닿은 획 또는 도형 전체를 지웁니다. 일부 픽셀만 지우는 방식이 아닙니다. |

마우스는 이동 속도로 압력을 추정하고 떨림을 줄입니다. 필압 펜은 장치가 제공하는 압력과 이동 정보를 사용합니다. 펜 뒤쪽 지우개 입력 경로도 지원하지만, 실제 장치별 필압·지우개 호환성은 별도 확인이 필요합니다.

### 색상과 도구별 기억

잉크 팔레트는 왼쪽부터 **파랑·빨강·주황·초록·보라·검정·흰색**입니다. 오른쪽 `…` 버튼으로 사용자 지정 색상을 고릅니다.

현재 단색은 팔레트의 체크 표시와 대비되는 테두리로 구분하며, ‘잉크 색상’ 제목 옆에도 색 이름을 표시합니다. 사용자 색은 … 버튼에 해당 색과 체크가 표시되고 클릭하면 다시 색을 지정할 수 있습니다. 순환색 사용 중에는 제목과 순환색 버튼에 상태를 표시합니다.

색상을 지정하려면 먼저 도구를 선택한 뒤 색을 선택하세요. 각 필기·도형 도구는 **단색과 순환색 켜짐 여부를 독립적으로 기억**합니다.

예를 들어 연필에 검정, 싸인펜에 순환색, 사각형에 빨강을 지정하면 도구를 바꿀 때마다 해당 색으로 돌아옵니다. 앱을 정상 종료하고 다시 실행해도 유지됩니다. 이전 버전의 설정을 처음 읽을 때는 기존 공통 색상을 각 도구의 초기값으로 사용합니다.

굵기·불투명도·순환색 변화 속도는 공통 설정입니다. 색을 변경해도 이미 그린 내용은 바뀌지 않습니다.

화이트보드와 일반 화면은 **도구별 색상과 순환색 켜짐 여부를 각각 따로 기억**합니다. 예를 들어 일반 화면의 싸인펜은 빨강, 화이트보드의 싸인펜은 흰색으로 지정할 수 있습니다. 화이트보드를 켜거나 끄면 현재 도구의 해당 모드 색상이 복원되며, 배경 버튼으로 화이트보드에 진입해도 동일하게 동작합니다. 보드 배경만 바꾸거나 일시적으로 화면 조작 모드로 전환해도 화이트보드 색상 설정은 유지됩니다.

업데이트 시 기존 도구별 색상을 두 모드의 초기값으로 복사합니다. 이후 변경은 해당 모드에만 적용되며 앱 재실행 후에도 유지됩니다. 굵기·불투명도·순환 속도는 기존처럼 공통 설정입니다.

### 순환색

팔레트 아래 **순환색** 버튼 또는 `Ctrl+Shift+9`로 켜고 끕니다.

- 한 획 안에서 이동 거리에 따라 빨강 → 주황 → 노랑 → 초록 → 파랑 → 보라 → 빨강 순으로 자연스럽게 변합니다. 무작위 색상 선택이 아닙니다.
- 순환색으로 그린 다음 획은 이전 색에서 이어집니다. 순환색을 새로 켜면 시작 색으로 돌아갑니다.
- 필기와 도형 모두 적용됩니다. 도형은 전체에 연속 그라데이션을 사용합니다.
- 단색을 고르면 현재 도구의 순환색이 꺼집니다.
- **설정 → 순환색**에서 변화 속도를 0.1~10.0배로 조절합니다. 기본은 2.0배입니다. 큰 값일수록 같은 거리에서 더 빠르게 변합니다.
- 변경된 속도는 새로 그리는 획에 적용됩니다. 진행 색상 자체를 도구별로 영구 저장하지는 않습니다.

### 불투명도와 굵기

- **잉크 불투명도:** 0%는 완전 투명, 100%는 불투명입니다. 기본 90%이며 단색·순환색 모두 적용됩니다.
- **굵기:** 도구 모음 슬라이더에서 0.5~18px 범위로 조절합니다. 기본은 9px입니다. 필압 도구는 이 값을 기준으로 실제 획의 굵기가 변합니다.
- 두 값 모두 새로 그리는 내용에 적용되고 기존 필기는 유지됩니다.

### 실행 취소와 삭제

- `Ctrl+Z`: 실행 취소. 최근 100단계까지 보관합니다.
- `Ctrl+Y`: 다시 실행.
- **모두 지우기** 또는 `Ctrl+Shift+Delete`: 모든 모니터의 필기를 삭제합니다.
- 실행 취소·다시 실행은 **커서가 있는 모니터**에 적용됩니다. 필기·도형 생성, 지우개 삭제, 모두 지우기를 되돌릴 수 있습니다.
- 취소 후 새로 그리거나 실제로 삭제하면 다시 실행 기록이 비워집니다.
- Ctrl+Z/Y 단축키는 그리기 모드에서만 앱이 처리합니다. 화면 조작 모드에서는 아래 프로그램이 처리합니다. 일시 조작용 Ctrl을 누르는 동안에도 그리기 모드가 켜져 있으면 앱의 실행 취소·다시 실행이 동작합니다.

### 화면 저장 (PNG)

- 도구 모음의 **화면 저장** 또는 **Ctrl+Shift+S**로 마우스가 있는 모니터 한 대를 저장합니다. 단축키는 설정의 **단축키 → 화면 저장 (PNG)**에서 변경합니다.
- 현재 보이는 화면과 필기를 저장하며, 화이트보드·확대 상태도 반영합니다. 도구 모음과 마우스 포인터는 포함하지 않습니다. PNG 크기는 해당 모니터의 실제 픽셀 크기입니다.
- **설정 → 화면 저장 · PNG**에서 **기본 파일명 사용**과 **저장 폴더**를 지정합니다. 기본은 자동 이름 사용, 사용자 사진 폴더 아래 ScreenBrush 폴더입니다.
- 자동 이름은 로컬 시각 기준 **screenbrush_년월일시분초.png**입니다. 예: `screenbrush_20260925143005.png`. 폴더가 없으면 저장할 때 만듭니다.
- 기본 파일명을 끄면 저장 창에서 이름과 위치를 선택합니다. 취소하면 저장하지 않습니다. 확장자는 항상 `.png`로 맞춥니다.
- 같은 이름이 있으면 `_1`, `_2` 등을 붙여 기존 파일을 보존합니다. 저장 결과는 도구 모음과 트레이 알림으로 안내합니다.
- 저장 중에는 중복 실행을 막으며, 저장 후 도구 모음의 기존 표시·숨김 상태를 복원합니다. 일반 화면 캡처 시 보이는 도구 모음만 잠시 숨깁니다.

## 3. 화이트보드

화면 대신 배경을 깔아 필기에 집중하는 모드입니다. **굵기 아래의 화이트보드 버튼** 또는 `Ctrl+Alt+B`로 켜고 끕니다.

배경 선택은 한 줄로 표시됩니다. 버튼 위에 마우스를 올리면 이름과 현재 단축키가 나옵니다.

| 왼쪽부터 | 배경 | 기본 선택 단축키 |
| --- | --- | --- |
| 흰색 칸 | 흰 배경 | Ctrl+Alt+Shift+1 |
| 검정 칸 | 검정 배경 | Ctrl+Alt+Shift+2 |
| 사용자 색 칸 | 저장한 사용자 배경색 | Ctrl+Alt+Shift+3 |
| 1 | 칠판 | Ctrl+Alt+Shift+4 |
| 2 | 줄노트 | Ctrl+Alt+Shift+5 |
| 3 | 도트 그리드 | Ctrl+Alt+Shift+6 |
| 이미지 무늬 버튼 | 설정에서 지정한 사용자 이미지 | Ctrl+Alt+Shift+7 |
| … | 사용자 배경색 선택 대화상자 | 버튼으로 지정 |

기본 배경 1·2·3은 각각 **3840×2160 PNG**이며 앱 리소스에 포함되어 있습니다. 사용자 색 변경은 잉크색 변경과 독립적입니다.

### 사용자 이미지 지정

1. **설정 · 단축키 → 화이트보드 · 사용자 이미지**로 이동합니다.
2. **이미지 파일 선택…**에서 PNG, JPG/JPEG, BMP, GIF 또는 TIF/TIFF 파일을 지정합니다.
3. **저장**합니다.
4. 도구 모음에서 사용자 이미지 버튼을 선택합니다.

이미지는 비율을 유지하면서 화면을 채우므로 가장자리가 잘릴 수 있습니다. 기본 배경은 4K 원본으로 읽고 사용자 이미지는 가로 1920픽셀로 읽습니다. 이미지 파일을 앱 폴더에 자동 복사하지 않으므로 이동하거나 삭제하면 다시 지정해야 합니다. 선택 시 읽을 수 없는 파일은 안내하고 기존 선택을 유지합니다. 저장된 이미지가 나중에 없어지면 실행 시 흰 배경으로 대체될 수 있습니다.

### 나가기와 화면 조작

**‘✓ 화이트보드 켜짐’ 버튼을 다시 누르거나 `Ctrl+Alt+B`를 누르면 화이트보드를 끕니다.** 배경만 사라지고 필기와 확대 상태는 유지됩니다.

Esc는 유지 옵션이 해제되어 있으면 화이트보드를 끄고 필기·기록·확대도 초기화합니다. 유지 옵션이 켜져 있어도 Esc에서는 화이트보드를 끕니다. 일시 조작 키를 누르는 경우에만 배경을 잠시 숨겼다가 키를 놓으면 다시 표시합니다.

배경을 선택하면 그리기가 켜집니다. 배경은 모든 모니터에 동일하게 적용되며, 배경을 바꿔도 필기와 실행 취소 기록은 유지됩니다. 화이트보드에서도 확대·축소와 오른쪽 드래그 이동을 사용할 수 있습니다. 일반 휠은 가려진 아래 프로그램으로 전달하지 않습니다.

### 자동 사라지기

**설정 → 자동 사라지기 → 자동 사라지기 사용**에서 켭니다. 기본은 **사용 안 함**이며, **Ctrl+Alt+Shift+A**로 켜고 끌 수 있습니다. 단축키는 설정에서 변경하거나 해당 단축키만 끌 수 있습니다.

- 마우스/펜을 놓아 선·도형을 완성한 순간부터 **3초 유지 → 1.5초 동안 페이드아웃**합니다. 오래 그린 선도 시작점부터 사라지는 것이 아니라 **선 전체가 동시에 같은 불투명도로** 사라집니다.
- 유지 시간은 0~60초, 페이드 시간은 0.1~10초로 조절합니다. 각 선·도형은 완성 시점을 기준으로 따로 계산합니다.
- 켜기/끄기와 시간 변경은 이후 완성되는 획부터 적용됩니다. 이미 페이드가 예약된 획은 기존 시간대로 사라지며 기존 일반 필기는 그대로 남습니다.
- 완전히 사라진 획은 실행 취소·다시 실행으로 되살아나지 않습니다. 소멸 전 실행 취소한 획도 원래 만료 시간을 따릅니다. 일반 화면·화이트보드·확대 상태에 동일하게 적용됩니다.

## 4. 화면 조작과 확대·축소

### 그리기와 아래 프로그램 조작

- **싸인펜·도형 등 도구를 선택하면 즉시 그리기가 시작됩니다. Esc를 누르면 아래 화면을 조작합니다.** 별도 모드 전환 버튼·트레이 메뉴·Ctrl+Shift+F2 기본 단축키는 제거했습니다.
- Esc는 도구 모음이 숨겨져 있어도 그리기를 종료합니다. **설정 → Esc 동작 → ‘Esc 후 필기·기록·확대 유지’**에서 처리 방식을 선택합니다.
- **체크 해제(기본):** 모든 모니터의 작성 내용과 실행 취소·다시 실행 기록을 삭제하고, 화이트보드를 끄며 확대를 100%로 초기화합니다. 도구를 다시 선택하면 빈 일반 화면에서 시작합니다.
- **체크:** 작성 내용과 Undo/Redo 기록·확대 상태를 유지하며 화면에서 숨깁니다. 화이트보드는 끕니다. 도구 선택 시 이전 필기·확대를 복원하지만 화이트보드는 자동으로 켜지지 않습니다.
- 설정을 저장한 뒤 다음 Esc부터 적용됩니다. 설정창에서 Esc로 취소하는 동작과 일시 조작 키에는 적용되지 않습니다. 도구별 색상·굵기·불투명도·배경 이미지 경로 등 사용자 설정은 삭제하지 않습니다. 이미 화면 조작 중인 상태에서 Esc는 다른 앱의 기본 동작을 방해하지 않습니다.
- 그리기 중 **왼쪽 Ctrl을 누르고 있는 동안** 아래 화면을 조작할 수 있습니다. 키를 떼면 그리기로 돌아옵니다.
- 일시 조작 키는 설정에서 좌우 Ctrl·Alt·Shift 또는 Space 중 선택할 수 있습니다. 이 키 자체는 아래 프로그램에도 전달됩니다.
- 일반 데스크톱 그리기 모드에서는 휠을 아래 창으로 전달합니다. 외부 앱의 입력 방식이나 권한에 따라 제한되면 일시 조작 키를 사용하세요.
- 필기는 화면 좌표에 고정되어 아래 문서의 스크롤을 따라 움직이지 않습니다. Esc로 화면 조작에 복귀하면 필기는 보이지 않으며, 유지 옵션에 따라 삭제하거나 보존합니다. 왼쪽 Ctrl 등 일시 조작 키를 누르는 동안의 기존 표시 동작은 유지됩니다.

### 확대 방법

기본은 **Shift+마우스 휠**입니다. 위로 돌리면 확대, 아래로 돌리면 축소합니다. 도구 모음의 −/+ 버튼이나 `Ctrl+Shift+↓/↑`도 사용할 수 있습니다.

| 설정 | 선택 범위 | 기본값 |
| --- | --- | --- |
| 보조키 + 마우스 휠로 확대·축소 | 사용 / 사용 안 함 | 사용 |
| 휠 보조키 | Ctrl·Shift·Alt 중 하나 이상 조합 | Shift |
| 확대·축소 간격 | 5~100%p, 5%p 단위 | 10%p |
| 최대 확대 배율 | 100~600%, 25% 단위 | 300% |

간격 10%p는 100% → 110% → 120%처럼 적용됩니다. 간격은 휠 한 칸, 단축키, 버튼에 공통 적용됩니다. 최소 배율은 100%입니다. 최대 배율을 현재보다 낮게 저장하면 확대 상태도 새 상한으로 내려갑니다.

휠 보조키는 **설정한 조합과 정확히 일치**해야 합니다. 예를 들어 Shift로 설정했다면 Ctrl+Shift+휠은 앱의 확대 조합이 아닙니다. 휠 확대는 일시 화면 조작보다 우선하며, 처리한 휠을 아래 앱에 전달하지 않습니다. 설정창·색 선택 대화상자에서는 휠 확대가 중지됩니다.

### 중심점, 이동, 원래 배율

- 처음 확대할 때 커서가 있는 모니터와 커서 위치를 기준으로 합니다. 확대 중에는 그 기준점을 유지합니다.
- 확대 상태에서 **오른쪽 버튼을 누른 채 드래그**하면 배경과 필기를 함께 이동합니다. 이동은 화면 경계로 제한되며 100%에서는 이동하지 않습니다.
- **100% 버튼** 또는 `Ctrl+Shift+0`으로 모든 모니터를 원래 배율로 돌립니다. 축소는 현재 기준점을 사용하며, 100%에 도달하면 원래 좌표가 됩니다.
- Esc로 화면 조작에 복귀하면 원래 화면을 표시합니다. 유지 옵션이 켜져 있을 때만 다음 도구 선택에서 확대를 복원합니다. 일시 조작 키를 누르는 동안에는 원래 화면을 표시하고 키를 놓으면 확대를 복원합니다.
- 데스크톱 확대는 실제 아래 화면과 필기를 함께 보여줍니다. 화이트보드는 선택한 배경과 필기를 함께 확대합니다.

## 5. 설정과 기본값

도구 모음의 **설정 · 단축키** 또는 트레이 우클릭 메뉴에서 엽니다. 설정 구역별로 스크롤할 수 있으며, 저장·취소 버튼은 창 아래에 있습니다.

| 항목 | 초기 기본값 |
| --- | --- |
| 도구 / 굵기 / 불투명도 | 싸인펜 / 9px / 90% |
| 잉크색 | 순환색 켜짐, 단색 저장값은 파랑 |
| 색 변화 속도 | 2.0배 |
| 도구 모음 시작 표시 | 트레이에서 시작 |
| 도구 모음 마지막 위치 기억 | 켜짐 |
| 화이트보드 | 꺼짐, 흰 배경 |
| 휠 확대 / 간격 / 최대 | Shift+휠 사용 / 10%p / 300% |
| 일시 화면 조작 키 | 왼쪽 Ctrl |

기존 사용자 설정은 초기 기본값으로 강제 변경하지 않습니다.

### Windows 시작 시 자동 실행

**시작 옵션 → Windows 시작 시 자동 실행**을 체크하고 저장합니다. 현재 사용자가 Windows에 로그인하면 설정한 트레이 또는 도구 모음 표시 방식으로 실행하고 화면 조작 상태로 대기합니다. 해제 후 저장하면 등록을 해제합니다.

자동 실행에는 현재 실행 파일 위치를 등록합니다. 앱 폴더를 옮겼거나 다른 PC로 복사했다면 새 위치에서 다시 설정하세요. Windows 작업 관리자의 시작 앱에서 별도로 사용 안 함으로 지정했다면 그곳에서도 사용으로 바꿔야 합니다.

**시작 시 표시**에서 트레이 또는 도구 모음 표시를 선택합니다. 저장 후 다음 실행부터 적용됩니다. 앱은 항상 화면을 가리지 않고 대기하며, 도구 버튼이나 단축키를 선택하면 그리기를 시작합니다. 이전 설정의 시작 모드 값은 무시합니다.

**도구 모음 마지막 위치 기억**은 기본으로 켜져 있습니다. 제목을 드래그해서 옮긴 위치를 설정 저장 또는 정상 종료 때 저장하고 다음 실행에서 복원합니다. 끄면 다음 실행부터 기존 기본 위치에서 엽니다. 트레이로 숨겼다가 다시 표시할 때는 현재 위치를 유지합니다. 모니터가 분리되거나 화면 크기가 바뀌면 사용 가능한 화면 안으로 위치를 보정합니다.

### 단축키별 활성화 / 비활성화

설정의 **단축키·색상 단축키·화이트보드 단축키** 목록에서 각 이름 앞의 체크박스로 해당 단축키 사용 여부를 선택합니다. **기본은 모두 켜짐**입니다.

- 체크 해제 후 **저장**하면 해당 단축키를 등록하거나 처리하지 않습니다. 다른 프로그램과 충돌하는 단축키만 골라 끌 수 있습니다. 실행 취소·다시 실행·앱 종료의 키보드 훅 처리도 제외됩니다.
- **버튼·컨트롤·트레이 메뉴는 정상적으로 사용할 수 있습니다.** 단축키를 꺼도 선택한 펜으로 그릴 수 있으며 버튼은 흐려지지 않습니다. 툴팁에는 ‘단축키 꺼짐’을 표시합니다.
- 꺼진 단축키의 입력 칸은 잠깁니다. 다시 체크하고 저장하면 기존 키로 활성화됩니다. 켜진 단축키끼리만 중복을 검사합니다.
- 보조키+마우스 휠 확대는 별도의 **‘보조키 + 마우스 휠로 확대·축소’** 옵션을 따릅니다. 확대·축소 키보드 단축키 체크와는 독립적입니다.
- 고정 Esc, 일시 화면 조작 키, 설정창 접근은 그대로 유지합니다. 앱 종료 단축키를 꺼도 × 버튼·트레이 메뉴로 종료할 수 있습니다.
- 기존 활성화 체크값은 그대로 유지하되 단축키에만 적용합니다. 기본 단축키 복원은 키 배정만 복원하며 체크값은 유지합니다.

### 단축키 변경과 복원

1. 설정의 **단축키**, **색상 단축키** 또는 **화이트보드 단축키**로 이동합니다.
2. 바꿀 입력 칸을 클릭하고 원하는 키 조합을 누릅니다.
3. 입력 즉시 중복·다른 앱과의 등록 충돌을 확인합니다. 충돌하면 하단에 바로 표시되고 저장 버튼이 비활성화됩니다. 키를 바꾸거나 해당 단축키 체크를 해제하면 다시 검사합니다.
4. 오류가 없으면 **저장**합니다. 설정창에서 확인된 키는 실행하지 않은 채 등록해 두므로 저장 시 처음으로 충돌을 검사하지 않습니다. 취소하면 기존 키로 복원합니다.

문자·숫자 키에는 Ctrl·Alt·Shift·Win 같은 보조키를 함께 지정합니다. 보조키만으로 기능 단축키를 만들 수는 없습니다. 숫자는 입력 칸에서 D1~D9처럼 표시될 수 있습니다. 설정창의 Esc는 취소이며, Alt+F4는 앱 종료 단축키가 켜져 있을 때 앱 전체를 종료합니다.

**기본 단축키 복원**은 기능 단축키와 일시 조작 키를 기본값으로 돌립니다. **기본 속도 복원**은 순환색 속도만 2.0배로 돌립니다. 둘 다 저장해야 적용됩니다. 취소·Esc·설정창 ×로 닫으면 편집 중인 설정은 적용하지 않습니다.

| 화이트보드 켜기 / 끄기 | Ctrl+Alt+B |
| 화이트보드 흰색 / 검정 / 사용자 색 | Ctrl+Alt+Shift+1 / 2 / 3 |
| 화이트보드 칠판 / 줄노트 / 도트 / 사용자 이미지 | Ctrl+Alt+Shift+4 / 5 / 6 / 7 |
| 앱 종료 | Alt+F4 |
| 일시 화면 조작 | 왼쪽 Ctrl을 누르는 동안 |

Esc는 그리기 중 화면 조작으로 돌아가는 고정 키이며 다른 기능에 단독 배정할 수 없습니다. 이전 설정에서 Esc에 배정했던 기능은 해당 기능 기본 키 또는 충돌하지 않는 키로 이전합니다. 설정창에서는 Esc로 설정창만 닫습니다. 도구 모음을 숨기려면 Ctrl+Shift+F1을 사용합니다. 도형의 Shift 제한도 고정 조작입니다. Ctrl+Z/Y는 그리기 모드에서만 앱이 처리하며, 설정창에서는 전역 기능 단축키를 잠시 중지합니다. 앱 종료 단축키가 켜져 있으면 Alt+F4는 설정창에서도 앱 전체를 종료합니다.

## 7. 설정 저장과 다른 PC로 옮기기

설정 파일은 `%LOCALAPPDATA%/ScreenBrush/settings.json`입니다. 탐색기 주소창에 `%LOCALAPPDATA%/ScreenBrush`를 입력하면 폴더를 열 수 있습니다.

- 설정창의 저장 버튼은 옵션을 파일에 기록합니다.
- 도구 모음에서 바꾼 도구·색상·굵기·불투명도·화이트보드 배경 종류는 정상 종료 시 저장합니다. 화이트보드의 켜짐 상태는 복원하지 않습니다.
- 도구별 색상은 `ToolColors`에 저장합니다. 필기 내용·실행 취소 기록은 저장하지 않습니다.
- 설정을 백업하거나 복사할 때는 앱을 먼저 정상 종료하세요. 실행 중인 앱이 종료할 때 파일을 다시 기록할 수 있습니다.

다른 PC에서는 다음 순서로 사용합니다.

1. **`artifacts/ScreenBrush` 폴더 전체**를 복사합니다. exe만 따로 복사하지 않습니다.
2. 대상 PC에 .NET 10 Desktop Runtime이 준비되어 있는지 확인합니다.
3. 복사한 폴더의 `ScreenBrush.exe`를 실행합니다. 개발 소스나 `.tools` 폴더는 실행에 필요하지 않습니다.
4. 개인 설정도 옮기려면 앱을 종료한 상태에서 settings.json을 대상 PC의 같은 사용자별 폴더로 복사합니다.
5. 사용자 이미지를 쓴다면 이미지 파일도 복사하고 설정에서 경로를 다시 지정합니다. 기본 4K 배경은 앱에 포함돼 있습니다.
6. 자동 실행을 원하면 대상 PC에서 새 실행 파일 위치로 다시 등록합니다.

## 8. 문제 해결과 제한 사항

| 상황 | 확인 / 조치 |
| --- | --- |
| 실행했는데 창이 안 보임 | 기본은 트레이 시작입니다. 트레이 아이콘 또는 Ctrl+Shift+F1으로 표시하세요. |
| 이미 실행 중이라는 안내 | 중복 실행 대신 기존 트레이 아이콘을 사용하세요. |
| 필기가 안 보임 | 그리기 모드인지, 지우개가 선택됐는지, 불투명도가 0%인지, 배경과 잉크가 같은 색인지 확인하세요. |
| 도구를 바꾸면 색이 바뀜 | 도구별 색상 기억에 따른 동작입니다. 해당 도구를 선택한 뒤 원하는 색을 지정하세요. |
| 화이트보드에서 못 나옴 | 켜짐 버튼을 다시 누르거나 현재 화이트보드 전환 단축키를 누르세요. 기본은 Ctrl+Alt+B입니다. |
| 사용자 배경이 안 열림 | 설정에서 파일 경로를 다시 지정하세요. 파일 이동·삭제·손상 여부를 확인하세요. |
| 단축키 저장 오류 / 오류 1409 | 다른 앱의 점유 또는 중복 조합일 수 있습니다. 안내된 기능의 조합을 변경하세요. 기본 Alt+F4 종료는 별도 키 처리 경로를 사용합니다. |
| 휠 확대가 안 됨 | 사용 옵션, 보조키 조합, 최대 배율을 확인하세요. 설정창·색 선택창을 닫고 정확한 조합으로 시도하세요. |
| 도구 모음 아래가 안 보임 | 창 안에서 스크롤하여 아래 기능에 접근하세요. |
| 아래 앱이 휠을 받지 못함 | 화이트보드에서는 전달하지 않습니다. 일반 데스크톱에서도 제한되는 앱은 일시 조작 키를 사용하세요. |
| 새 버전이 적용되지 않음 | 실행 중인 앱을 완전히 종료한 뒤 갱신된 실행 파일을 실행하세요. |

- 확대 데스크톱은 약 66ms 주기로 캡처를 요청하며 실제 갱신은 처리 부하에 따라 달라집니다. 필기는 별도 WPF 벡터 렌더링입니다. 화이트보드는 데스크톱을 반복 캡처하지 않습니다.
- 데스크톱 확대에서 재귀 캡처를 막기 위해 확대 창과 도구 모음을 캡처에서 제외합니다. 이때 화면 공유·스크린샷에 확대 화면과 필기가 보이지 않을 수 있습니다. 보호된 영상이나 보안 화면은 캡처가 제한될 수 있습니다.
- 모든 화면·GPU·펜·외부 앱에서 동일한 입력 지연을 보장하지 않습니다. 긴 연필 획은 곡선·질감 생성 비용이 더 큽니다.
- 실행 중 모니터 구성이나 배율을 바꾸면 앱을 재실행하세요. 혼합 DPI 다중 모니터와 실제 필압 펜은 추가 실기기 확인이 필요합니다.
- 필기가 문서 스크롤을 따라가는 기능, 문서/PDF 뷰어, 필기 파일 저장·불러오기는 포함하지 않습니다.

## 9. 개발자용 빌드와 검증

C# / .NET 10 / WPF / Win32 기반이며 앱은 외부 NuGet 패키지를 사용하지 않습니다. `.tools/dotnet`에 SDK가 있으면 빌드 스크립트가 우선 사용하며, 없으면 PATH의 dotnet을 사용합니다.

```powershell
# 빌드 및 artifacts/ScreenBrush 배포 폴더 생성
powershell -ExecutionPolicy Bypass -File .\build.ps1

# 기본 검사와 필기 샘플 생성 포함
powershell -ExecutionPolicy Bypass -File .\build.ps1 -Check -Samples

# 별도 테스트 창에서 실제 마우스/키보드 입력 검사
powershell -ExecutionPolicy Bypass -File .\build.ps1 -DesktopCheck
```

실제 입력 검사는 마우스를 움직이고 테스트 창을 표시하므로 실행 중에는 다른 작업을 잠시 멈춥니다. 최신 기본 검사는 765개 통과했습니다. 시작 표시 두 가지, Esc 복귀, 단축키 비활성화, PNG 저장 및 설정창 표시도 별도로 확인했습니다.

빌드 후 검사 DLL은 `tests/ScreenBrush.Checks/bin/Release/net10.0-windows/ScreenBrush.Checks.dll`입니다. 사용 중인 dotnet으로 실행합니다.

| 검사 인자 | 검사 내용 |
| --- | --- |
| 인자 없음 | 설정·단축키·좌표·렌더링·색상 저장 등 기본 검사 |
| --whiteboard | 화이트보드 전환·확대·필기 보존 및 실제 마우스 입력 |
| --startup-options | 시작 옵션과 도구 모음 표시/숨기기 |
| --settings-preview | 설정창 렌더 확인 |
| --alt-f4 / --settings-alt-f4 / --toggle-hotkeys | 종료 및 도구 모음 전환 키 검사 |
| --performance / --capture-performance | 도형·필기 생성 또는 캡처 측정 |
| --board-performance artifacts/board-perf.json | 배경별 도형 미리보기 갱신 비교 |
| --resources | CPU·메모리·핸들 사용량 측정 |

UI·샘플·측정 결과는 artifacts에 생성됩니다. 아이콘 원본과 생성 기록은 `src/ScreenBrush/Assets`, 화이트보드 배경과 생성 기록은 `src/ScreenBrush/Assets/Whiteboard`에 있습니다.


이전 버전 설정의 삭제된 기능 이름(Toggle·Text)은 JSON을 설정 객체로 변환하기 전에 정리합니다. 사용자 지정 단축키·색상·기타 설정은 유지합니다. 설정 읽기에 실패해 기본값으로 실행된 경우에는 종료 시 원래 설정 파일을 자동 덮어쓰지 않습니다. 설정창에서 명시적으로 저장한 경우에는 새 설정을 적용합니다.


전체 코드 재검토에서는 잘못된 설정 복구, 색상 선택창 Esc, 확대 캡처 실패 복원, 저장 중 종료, 종료 후 콜백, 빈 지우개 작업의 실행 취소 이력을 보완했습니다. 자동 검사 외에 실제 마우스·키보드 입력으로 확대 필기·실행 취소·화이트보드·PNG 저장·트레이·종료 동작을 확인했습니다. 자세한 검증 범위와 제한은 검토 및 수정.md에 기록합니다.

화이트보드는 켜기 버튼·화이트보드 단축키·배경 선택으로 직접 켭니다. 앱 재시작이나 Esc 후 필기 도구 선택만으로 켜지지 않습니다. 화이트보드에서 지정한 도구별 색상·순환색과 배경 종류·이미지 설정은 그대로 기억합니다.
